### 👋 About me

3rd-year CS student at **Bauman Moscow State Technical University** (CAD Systems dept), currently specializing in **Data Science**.

- 🎯 **Focus:** Data Science — deepening my skills in Python, statistics, and applied ML/NLP
- 🔭 **Working on:** a 12-week research project (НИРС) on comparative topic modeling of Russian-language texts — TF-IDF, LDA, NMF, and Word2Vec on the Lenta.ru dataset
- 🌱 **Learning:** pandas, data analysis workflows, and statistical methods
- 🧰 **Also comfortable with:** full-stack development — FastAPI + PostgreSQL backend, SwiftUI iOS app
- 📫 **Reach me:** [Telegram @stab1lno](https://t.me/stab1lno)
